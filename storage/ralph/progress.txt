## Codebase Patterns

- **SFC pattern**: Todos componentes Livewire são Single-File Components com `@php new class extends Component { } @endphp`
- **Kanban columns**: features usam `FeatureStatus` (Draft, Backlog, Todo, Doing, Done); tasks usam `TaskStatus` (Inbox, Backlog, Todo, Doing, Done)
- **Feature status é computed**: baseado nas tasks (todas done = Done, alguma doing = Doing, etc.)
- **Done column**: filtrar por `completed_at` na semana corrente para tasks
- **Imports Livewire**: `use Livewire\Attributes\Url;` para `#[Url]`, `use Livewire\Attributes\Computed;` para `#[Computed]`
- **Limits pattern**: array `$limits` com status como key, `loadMore()` incrementa 20
- **Refresh pattern**: `unset($this->computedProp)` para invalidar computed properties
- **Feature card component**: `resources/views/components/feature-card.blade.php` — Blade component com @props
- **Project-detail tabs**: board, features, docs, metrics — board tab contém kanban de features
- **Pre-existing test failures**: 10 testes falhando (AiInsightsTest, AiIntegrationTest, AnalyticsPageTest, DocumentIntegrationTest) — não relacionados ao drill-down
