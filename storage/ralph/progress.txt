## Codebase Patterns

- **Feature card component**: `resources/views/components/feature-card.blade.php` — Blade component com props `$feature`, `$expanded`, `$showProject`
- **Feature ID format**: `#F-{id}` (ex: #F-12) — padrão para referenciar features
- **Card visual pattern**: flex layout com título à esquerda, metadata à direita, badges row abaixo
- **Pre-existing test failures**: AiInsightsTest, AiIntegrationTest, AnalyticsPageTest, DocumentIntegrationTest — não relacionadas a feature cards
- **Copy-to-clipboard pattern**: Alpine `x-data="{ copied: false }"` + `x-on:click.stop` + `x-show` toggle entre texto original e "Copiado!" + `:class` para cor emerald-400
- **Feature modal component**: `resources/views/components/⚡feature-modal.blade.php` — SFC Livewire com `$featureId`, `$title`, `$spec`, etc. Header mostra ID `#F-{id}` ao editar
