## Codebase Patterns

- **Feature modal SFC**: `resources/views/components/⚡feature-modal.blade.php` — Single-File Component Livewire
- **Feature status é computado**: `Feature::status` é um Attribute accessor baseado no status das tasks (todas Done = Feature Done)
- **Toggle view/edit pattern**: usar property bool + método toggleXxx() que auto-salva antes de inverter. Referência: `editingPrompt` no task-modal, `editingSpec` no feature-modal
- **Livewire test pattern**: `Livewire::test('feature-modal')->call('open', $feature->id)->assertSet('editingSpec', false)`
- **Markdown rendering**: `{!! Str::markdown($var) !!}` dentro de `prose prose-sm prose-invert` container
